A portfolio of six end-to-end data analytics, machine learning, quantitative finance, and business intelligence projects.

## Projects in this Portfolio

1. **covid19-pandemic-analysis**: Pandemic epidemiology, regional infection dynamics, and socioeconomic correlations.
2. **cracow-real-estate-pricing**: Real estate pricing analysis and regression modeling for flats in Cracow, Poland.
3. **fx-trading-analysis**: Quantitative trading performance, drawdowns, and risk profile evaluation of FX algorithmic strategies.
4. **global-terrorism-eda**: Security analytics and geospatial casualty distribution using the Global Terrorism Database.
5. **Music-Store-Analysis**: Comprehensive SQL database analysis of digital music store commercial operations.
6. **polar-watch-fitness-analysis**: Fitness vitals, heart rate kinetics, and caloric expenditure modeling.
